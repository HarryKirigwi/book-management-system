# Book Management System

A web-based application built with PHP and PostgreSQL to manage a personal book collection. Users can register, log in, and perform CRUD operations (Create, Read, Update, Delete) on books, with a clean, responsive UI styled with CSS.

## Features
- **User Authentication:** Register and log in with username, email, and password (includes password visibility toggle).
- **Book Management:** Add, edit, and delete books with fields for title, author, publication year, and recommendations.
- **Success Popups:** Visual feedback for successful book operations before redirecting to the dashboard.
- **Responsive Design:** Futuristic UI with CSS gradients and media queries for mobile compatibility.
- **Secure Configuration:** Database credentials stored in a `.env` file, excluded from version control.

## Tech Stack
- **Backend:** PHP 8.x
- **Database:** PostgreSQL 15.x
- **Frontend:** HTML, CSS (custom styles), minimal JavaScript
- **Environment:** `.env` file for configuration
